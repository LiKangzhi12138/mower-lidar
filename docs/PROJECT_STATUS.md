当前主路线是**实验姿态校正 → 法向约束 RANSAC → DBSCAN → 三维候选/二维图**。R3.2 的 142 实验已有有限人工观察：两方法都保留了外围大结构的大部分点，但绿色地面层和灰色未聚类区域有待逐点核查；不能由视觉、点数或簇数判断准确率。R3.3 建议优先人工看 143、144、145、149；其余帧也不视为通过物理验收。离线计时只代表本机算法段，不代表整机在线延迟。

尚缺：可信 NPZ 转换链和单位核实、雷达轴到车体轴的正式外参、0.415 m 的内部原点参考与误差、143～149 实际安装记录；带真值的地面/障碍标注及距离/方位精度测试；ROS 2 在线接入和 Jetson 性能/端到端时延验证。本工程不输出经过安全认证的检测结果，也不承担控制与规划。

历史报告保持原样，其中 `outputs/` 链接指向本地被 Git 忽略的实验产物；GitHub 克隆只保留源代码、配置、报告和一张经过检查的示例图。
